VI. CONFIDENCE-GATED TRUST FUSION — LTCA CORE CONTRIBUTION  ADAPTIVE CONTROL
✗  NAIVE FUSION — the problem
T = 0.5·M + 0.3·R + 0.2·H  (fixed weights)
Fixed weights treat all signals equally regardless of model confidence. A noisy retrieval match can override a correct, high-confidence model decision → unsafe override → wrong policy action.
Example: M(x)=0.05 (clearly malicious) + R(x)=0.90 (wrong retrieval) → T=0.325 → QUARANTINE ✗ should be BLOCK

CORE NOVELTY — THESIS DEFENCE STATEMENT
The LTCA extends edge-based intrusion detection into a multi-signal trust scoring system where decisions are regulated through a confidence-aware control mechanism. Rather than combining model output, retrieval context, and behavioural history with fixed weights, LTCA detects the model confidence regime and dynamically adjusts signal contributions to prevent contextual signals from overriding high-confidence correct decisions — transforming a static fusion pipeline into an adaptive decision-making framework.
